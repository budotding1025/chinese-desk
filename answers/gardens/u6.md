# 语文园地六参考答案

> 做完再看。

## 默写全文

尺有所短，寸有所长。（俗语）

机不可失，时不再来。（俗语）

差之毫厘，谬以千里。（俗语）

病从口入，祸从口出。（俗语）

一言既出，驷马难追。（俗语）

比上不足，比下有余。（俗语）

## 意思

- 尺有所短，寸有所长。 → 每个人都有短处，也有长处；不要只看一面。
- 机不可失，时不再来。 → 好机会不能放过，错过就很难再有。
- 差之毫厘，谬以千里。 → 开头差一点点，结果可能错出很远。（谬读 miù）
- 病从口入，祸从口出。 → 生病常因饮食不慎；惹祸常因说话不慎。
- 一言既出，驷马难追。 → 话一说出口，四匹马拉的车也追不回；说话要算数。
- 比上不足，比下有余。 → 跟更好的比还差些，跟更差的比还强些；常用来自我宽慰或客观看待。

## 背景

六句多为相对工整的俗语。须会背、会默、懂每句意思，并能说说适用场合。
