# 错题档案

凡练习（工作日迷你 / 周末 / 整卷摸底）中的错题，都记在这里。  
**考试前**：筛出相关单元、状态仍为「未掌握」的条目 → 复习或再练。

孩子可自选练习顺序，但**错题不要丢**。

## 怎么记

1. 卷面题号旁勾选「本题做错」  
2. 在下表新增一行（或打印 `错题登记表` 手写后周末誊入）  
3. 订正后把状态改为「已订正」；隔几天再练对，改为「已掌握」

## 类型代码（方便筛选）

`生字` `形近组词` `多音` `字义` `园地默写` `园地理解` `句型仿写` `短阅读` `作文` `课外阅读`

## 考前复习步骤

1. 只看本单元（或本期考试范围）且状态 ≠ 已掌握  
2. 遮住「正确写法」，口答或默写  
3. 仍错：当日再记一行，来源写「错题再练」  
4. 全对：状态改「已掌握」
