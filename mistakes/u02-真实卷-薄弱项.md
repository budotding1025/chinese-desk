# 以后练什么（按家长定的重点）

来源：第二单元校内卷（**订正后的卷面**，63.5/70）。  
成语两处按「已改过」处理，不当原始错因。

加练纸：`printables/skills/weak-focus.pdf`  
答案：`printables/skill-answers/weak-focus-answers.pdf`

## 五块，每次不必全做

1. **拼音易错读音**（尤其声调）  
   囚犯 qiú、蝙蝠 biān、避开 bì、一溜烟 liù、荧屏 yíng、嚷嚷 rǎng。

2. **形近字组词**  
   纲/冈、末/沫、即/既、具/俱。口头能分：提纲、井冈山、纲要。

3. **成语积累 + 运用**  
   先根据意思默写四个字，再选一个填进句子。本单元先盯：口若悬河、无计可施、纸上谈兵。

4. **阅读：用方法抓大意**  
   三步：①写了谁/什么　②按顺序做了什么　③结果或道理。连成 1～2 句，不要只抄一个词。

5. **的 / 地 / 得**  
   - 的：后面多为事物（红红的太阳）  
   - 地：后面多为动作（高兴地跑）  
   - 得：前面是动作，后面说得怎么样（做得快）；**觉得**用得。
