# 语文书桌 / Chinese Desk

与**统编四上教材（2024）**同步。框架对齐翻翻英语：**主页 · 路径 · 记录**。

**网址：[https://budotding1025.github.io/chinese-desk/](https://budotding1025.github.io/chinese-desk/)**  
本机：`python desk_server.py` → http://127.0.0.1:8732/

## 三个入口

| 入口 | 做什么 |
| --- | --- |
| **主页** | 当日练习（当前默认**第1课《观潮》**） |
| **路径** | 按单元 → 每一课 → 语文园地 → 冲刺/摸底；点课选练习项 |
| **记录** | 卷面对照红笔圈错题 · 错题库 |

### 路径里每一课

字词默写 · 形近组词 · 多音字 · 课文默写（有背诵要求时）· 课文大意理解  

### 语文园地

日积月累默写 · 大意理解 · 作者/背景知识  

## 主色

橙红 `#E85D04` · 橙黄 `#F4A261`

## 每课可打印 A4

| 文件 | 时长 | 内容 |
| --- | --- | --- |
| `printables/lessons/Lxx-课题-每日10分钟.pdf` | ≈10 分钟 | 字词听写、组词/成语、多音辨认、句型仿写 |
| `printables/lessons/Lxx-课题-背诵默写10分钟.pdf` | 另 +10 分钟 | 仅有背诵要求的课 |

## 单元冲刺 A4

`printables/sprint/U1|U2|U3-…单元冲刺.pdf`（测前）  
完整学校卷数字化仍在 `printables/full/`。

App 主页 / 路径 / 记录均可下载。

## 改「今日课文」

路径里点某一课 →「设为今日课文」。默认课次在 `data.js` 的 `currentBookLesson`（现为 8）。
