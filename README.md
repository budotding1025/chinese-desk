# 语文书桌 / Chinese Desk

与**统编四上教材**同步。框架对齐翻翻英语：**主页 · 路径 · 记录**。

**网址：[https://budotding1025.github.io/chinese-desk/](https://budotding1025.github.io/chinese-desk/)**  
本机：`python desk_server.py` → http://127.0.0.1:8732/

## 三个入口

| 入口 | 做什么 |
| --- | --- |
| **主页** | 当日练习（当前默认**第8课《蝴蝶的家》**） |
| **路径** | 按单元 → 每一课 → 语文园地；点课选练习项 |
| **记录** | 错题记录 · 单元冲刺测试 PDF · 重难点练习 PDF |

### 路径里每一课

字词默写 · 形近组词 · 多音字 · 课文默写（有背诵要求时）· 课文大意理解  

### 语文园地

日积月累默写 · 大意理解 · 作者/背景知识  

## 主色

橙红 `#E85D04` · 橙黄 `#F4A261`

## 打印材料

仍在 `printables/`（默写纸、考点练习、周末、整卷摸底）。App 与打印可并用。

## 改「今日课文」

路径里点某一课 →「设为今日课文」。默认课次在 `data.js` 的 `currentBookLesson`（现为 8）。
