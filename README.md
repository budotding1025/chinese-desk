## 三种练习（第 1–3 单元已齐）

| 类型 | 何时 | 目录 | U1–U3 |
| --- | --- | --- | --- |
| **工作日迷你** 8–15 分钟 | 工作日（可隔天） | `printables/weekday/` | ✅ |
| **周末** 作文仿写 + 教委课外阅读 | 周末 | `printables/weekend/` | ✅ |
| **大测摸底** 单元整卷 | 单元测前 1–2 天 | `printables/full/` | ✅（U3 整卷仅 1–2 页） |

工作日四块：易错字词（生字/形近/多音/字义）→ 园地 → 1～2 句仿写 → 短诗/短文少量题。  
周末两块：作文仿写支架 + 课外阅读理解。  
详细推荐日程：[`schedule.md`](schedule.md)。

## 错题档案（必做习惯）

1. 卷面勾「本题做错」或填 [`printables/weekday/错题登记表`](printables/weekday/错题登记表.docx)  
2. 记入 [`mistakes/错题档案.md`](mistakes/错题档案.md)  
3. **考试前**：只复习该单元「未掌握」错题，再练仍错继续留档  

## 怎么选（推荐 ≠ 强制）

- 学校还没上到该单元 → 可跳过或只做字词预习  
- 工作日很累 → 可只做 5 分钟错题再练  
- 周末作文已在学校写过 → 可只做课外阅读理解  
- 测前时间紧 → 优先 **错题档案 + 园地默写**，整卷可选
